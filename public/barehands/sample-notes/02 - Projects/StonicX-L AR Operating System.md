# StonicX-L AR Operating System

## Architecture Pillars
1. **AI Memory Vault:** Markdown-backed persistent memory modeled after Obsidian.
2. **Backtalk Voice Loop:** Push-to-Talk / Hands-free speech synthesis with ducking.
3. **AI Visualizer:** Four reactive procedural faces (Board, Neural, Radial, Rain).
4. **Barehands AR:** Naked canvas MediaPipe hand tracking and glass card spatial UI.
